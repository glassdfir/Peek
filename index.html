PE header viewer. Runs entirely in your browser; the file never leaves this machine and is never executed.

Drop a Windows executable here

EXE, DLL, SYS, OCX, CPL, SCR, EFI, or anything else with a PE header. Or use Open file… above.

Nothing is uploaded or run. Parsing is read-only and tolerant of damaged headers.

What you get:
  • SHA-256 / SHA-1 / MD5, imphash and Rich-header hash, ready to copy into a ticket or a search
  • Headers, data directories, sections with entropy, imports (incl. delay-load), exports, resources, version info, manifest
  • Debug/PDB path, Rich header toolchain, TLS callbacks, .NET header, load config, Authenticode presence, overlay
  • Triage findings: packer names, W+X sections, odd entry points, timestomping, injection-style imports and more

Peek

A read-only Portable Executable viewer for triage. Everything is parsed in the page with no server and no network.

  • Findings are observations, not verdicts. Many legitimate installers, games and runtimes trip the packer and overlay checks; many malware samples trip none. Use them to decide where to look next.
  • Signature shows only that an Authenticode blob is present and which names appear in it. The chain and the file hash are not verified here. Use signtool verify or Get-AuthenticodeSignature for that.
  • imphash follows pefile's algorithm (lowercase, extension stripped, ordinals resolved for oleaut32, ws2_32 and wsock32 from pefile's own tables), so it is comparable with VirusTotal and most sandboxes.
  • Rich hash is the MD5 of the decoded Rich header, as pefile computes it.
  • Entropy is Shannon entropy in bits per byte. Plain code is usually 5.5–6.8; above ~7.2 means compressed or encrypted.
  • JSON export contains the full parse plus findings, for reports or for feeding other tools.

Shortcuts: ? help, o open file, Esc close.
